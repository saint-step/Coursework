# Coursework

**Студент**: Фролов С. В., группа ПИ-53
**Дисциплина**: Объектно-ориентированное программирование, 3 семестр
**Преподаватель**: доцент, к.т.н. Рахманин Д. С.

- Тема: Проектирование и разработка текстовой пошаговой RPG-игры в сеттинге фэнтези.

- Цель: Создать текстовый симулятор ролевой игры для управления персонажем в данже, включающий бои с монстрами и прокачку навыков. 
  Для любителей жанра RPG и студентов, изучающих ООП.

- Основной сценарий: Пользователь создает героя, попадает в локацию и вводит команды «осмотреть», «идти», «атаковать».
  При встрече с врагом запускается пошаговый бой, за победу в котором начисляется опыт и повышается уровень.

- Границы: Программа является консольным приложением без графического интерфейса. Мир ограничен заранее заданными комнатами.

- Почему подходит для ООП: Сущности - Персонаж, Маг, Воин, Предмет, Монстр, образуют иерархию: Маг и Воин наследуются от абстрактного
  Персонажа и по-своему реализуют метод «Атаковать». Персонаж использует предметы и заклинания из инвентаря, а Монстр взаимодействует 
  с ним в бою через обмен значениями здоровья и урона.

**Структура проекта**:
- cpp/ — исходники на C++
- java/ — исходники на Java
- docs/ — документация

**Сборка и запуск**:
- C++: g++ cpp/src/main.cpp -o app && ./app
- Java: javac java/src/Main.java && java -cp java/src Main
